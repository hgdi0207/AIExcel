# AI Excel 网页界面设计规范文档

**版本**: 1.0  
**日期**: 2026-09-16  
**基准竞品**: [GPTExcel.uk](https://gptexcel.uk)

---

## 1. 设计目标

### 1.1 核心原则

1. **即看即用**：首页直接展示核心功能，无需登录即可试用
2. **渐进式引导**：试用达到限额或需要高级功能时，引导注册/登录
3. **现代简洁**：清爽、专业、高效的 SaaS 风格
4. **信任建立**：通过视觉设计传达可靠性和专业度

### 1.2 用户旅程

```
访问首页 → 查看功能卡片 → 点击进入工具页 → 
直接试用（前N次免费）→ 达到限额 → 弹出登录引导 → 
注册/登录 → 解锁完整功能
```

## 2. 视觉设计系统

### 2.1 配色方案

#### 主色调
- **品牌绿色（Primary Green）**: `#5FD8A0`
  - 用于：主要按钮、工具图标、hover 状态、功能卡片高亮
  - 语义：积极、高效、AI 赋能

- **深色文字（Text Primary）**: `#1A202C`
  - 用于：标题、正文、导航文字

- **中灰文字（Text Secondary）**: `#718096`
  - 用于：副标题、说明文字、辅助信息

#### 辅助色
- **背景白色**: `#FFFFFF`
- **浅灰背景**: `#F7FAFC`（卡片、分区背景）
- **边框灰**: `#E2E8F0`
- **警告橙**: `#F6AD55`（额度提示）
- **成功绿**: `#48BB78`
- **错误红**: `#F56565`

#### 渐变点缀（用于标题强调）
- **彩虹渐变**: `linear-gradient(90deg, #5FD8A0 0%, #7EC8E3 50%, #C084FC 100%)`
- 仅用于：首页主标题关键词（如 "Spreadsheet Automation"）

### 2.2 字体系统

#### 字体族
- **西文主字体**: `Inter`, `-apple-system`, `BlinkMacSystemFont`, `system-ui`
- **中文主字体**: `PingFang SC`, `Microsoft YaHei`, `sans-serif`
- **代码/公式字体**: `JetBrains Mono`, `Consolas`, `Monaco`, `monospace`

#### 字号体系（响应式）
| 用途 | 桌面端 | 移动端 |
|------|--------|--------|
| 主标题（H1） | 48px / Bold | 32px / Bold |
| 副标题（H2） | 36px / SemiBold | 26px / SemiBold |
| 小标题（H3） | 24px / Medium | 20px / Medium |
| 正文 | 16px / Regular | 15px / Regular |
| 辅助文字 | 14px / Regular | 13px / Regular |
| 按钮文字 | 16px / Medium | 15px / Medium |

#### 行高规范
- 标题：1.2
- 正文：1.6
- 按钮：1

### 2.3 圆角规范
- **小圆角（Small）**: 6px - 用于按钮、输入框、Tag
- **中圆角（Medium）**: 12px - 用于功能卡片
- **大圆角（Large）**: 20px - 用于模态弹窗、主要容器

### 2.4 阴影系统
- **轻阴影（Hover）**: `0 2px 8px rgba(0,0,0,0.08)`
- **标准阴影（Card）**: `0 4px 12px rgba(0,0,0,0.10)`
- **重阴影（Modal）**: `0 12px 32px rgba(0,0,0,0.15)`

## 6. 响应式设计

### 6.1 断点（Breakpoints）

| 尺寸 | 宽度范围 | 备注 |
|------|---------|------|
| Mobile | 320px - 767px | 单列布局 |
| Tablet | 768px - 1023px | 侧边栏可收起 |
| Desktop | 1024px+ | 完整布局 |

### 6.2 移动端适配规则

1. **导航**: 侧边栏改为底部 Tab 栏或汉堡菜单
2. **功能卡片**: 单列堆叠
3. **输入输出区**: 上下堆叠（Input 在上，Result 在下）
4. **字号**: 主标题 32px，正文 15px
5. **Padding**: 整体减半（24px → 12px）
6. **按钮**: 改为全宽
7. **装饰元素**: 隐藏曲线装饰

---

## 7. 动效规范

### 7.1 过渡动画（Transitions）

- **通用速度**: 0.3s
- **缓动函数**: `ease-in-out`
- **应用场景**:
  - 按钮 hover
  - 卡片 hover
  - 输入框 focus
  - 颜色变化

### 7.2 交互反馈

- **按钮点击**: 缩放至 0.98（100ms）
- **卡片点击**: 轻微下陷阴影（100ms）
- **输入聚焦**: 边框颜色渐变 + 外发光
- **复制成功**: 按钮文字变"Copied!" + 绿色背景闪烁

### 7.3 加载状态

- **按钮加载**: 旋转圆圈图标 + 文字变"Loading..."
- **内容加载**: 骨架屏（灰色占位块，脉动动画）
- **全局加载**: 顶部进度条（绿色，从左到右）

### 9.2 装饰元素

**曲线流线（Curved Lines）**:
- 风格: 手绘风，SVG 路径
- 颜色: 半透明绿色 `rgba(95,216,160,0.3)` 或橙色 `rgba(251,146,60,0.3)`
- 用途: 首页 Hero 区装饰
- 位置: 左上角、右上角
- 响应式: 移动端隐藏

**图标风格**:
- 类型: Line icons（线性图标）
- 粗细: 2px
- 圆角: 圆润端点
- 颜色: 根据功能分类
  - Formulas: 绿色 `#5FD8A0`
  - Scripts: 橙色 `#F6AD55`
  - SQL: 青色 `#4299E1`
  - AI Chat: 紫色 `#9F7AEA`

## 10. 可访问性（Accessibility）

### 10.1 颜色对比度

- **文字与背景**: 至少 4.5:1（WCAG AA 标准）
- **主按钮**: 黑底白字，对比度 21:1
- **禁用状态**: 明确的灰色区分

### 10.2 键盘导航

- **Tab 顺序**: 逻辑流畅（从左到右，从上到下）
- **Focus 样式**: 明确的绿色外框
- **快捷键**:
  - `Ctrl/Cmd + Enter`: 提交生成
  - `Ctrl/Cmd + K`: 聚焦搜索框
  - `Esc`: 关闭弹窗

### 10.3 屏幕阅读器

- **语义化 HTML**: 使用 `<header>`, `<nav>`, `<main>`, `<section>`
- **ARIA 标签**: `aria-label`, `aria-describedby`
- **图标**: 必须配 `aria-label` 或可见文字

## 11. 性能优化建议

### 11.1 加载优化

- **首屏内容**: 内联关键 CSS（<14KB）
- **字体**: 使用 `font-display: swap`
- **图片**: WebP 格式，懒加载
- **SVG 图标**: 内联或雪碧图

### 11.2 动画性能

- **优先使用**: `transform` 和 `opacity`（GPU 加速）
- **避免**: `width`, `height`, `top`, `left` 动画
- **降级**: 低端设备禁用非关键动画
